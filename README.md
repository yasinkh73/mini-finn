# mini-FINN

En responsiv studentmarkedsplass laget med HTML, CSS og JavaScript.

## Kjør lokalt
Åpne `index.html` i en nettleser. Ingen installasjon eller database er nødvendig.

## Funksjoner
- Søk etter annonser
- Filtrer på kategori
- Vis annonse med beskrivelse og kontaktinformasjon
- Favoritter
- Publiser nye annonser med validering
- Lagring i nettleserens `localStorage` (på samme enhet/nettleser)

## Publiser gratis med GitHub Pages
1. Logg inn eller opprett en konto på https://github.com/
2. Opprett et nytt repository, for eksempel `mini-finn`. Velg Public.
3. Last opp `index.html` og `README.md` til repositoryets rotmappe.
4. Gå til **Settings → Pages**.
5. Under **Build and deployment**, velg **Deploy from a branch**.
6. Velg branch `main` og mappe `/ (root)`, og trykk **Save**.
7. Vent litt, og åpne URL-en GitHub Pages viser på samme side. Den vil normalt ligne `https://DITT-BRUKERNAVN.github.io/mini-finn/`.

## Viktig
GitHub Pages-lenken blir først aktiv etter at du selv har publisert repositoryet. Jeg kan klargjøre filene, men kan ikke opprette/publisere i din GitHub-konto uten tilgang. Dette er en prototype: annonser og favoritter lagres kun lokalt i den enkelte nettleseren, ikke på en felles server. Kontaktinformasjon og eksempelannonser er testdata.
