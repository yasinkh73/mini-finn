# mini-FINN

En responsiv studentmarkedsplass laget med HTML, CSS og JavaScript.

## 🚀 Live Demo
Du kan teste den levende applikasjonen her:  
👉 **https://yasinkh73.github.io/mini-finn/**

## 💻 Kjør lokalt
Åpne `index.html` i en nettleser. Ingen installasjon eller database er nødvendig.

## ✨ Funksjoner
- Søk etter annonser
- Filtrer på kategori
- Vis annonse med beskrivelse og kontaktinformasjon
- Favoritter
- Publiser nye annonser med validering
- Lagring i nettleserens `localStorage` (på samme enhet/nettleser)

## ⚠️ Viktig info for testere
Dette er en prototype for et studentmarked. Siden applikasjonen bruker `localStorage`, lagres publiserte annonser og favoritter lokalt i din egen nettleser. Data deles ikke på en felles server, og eksempelsidene bruker testdata.
